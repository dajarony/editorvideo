# GNT-001 — F1: auditoría y entorno reproducible de AEGS
Estado: Aprobado (por dajarony, 2026-10-12)

## TAREA
Primera fase del plan de integración AEGS + Aura Motion Studio (decisión del usuario: narración primero, AEGS como dependencia fijada, plan F1–F6 con PRs). Dejar AEGS instalable, comprobable y auditado antes de conectarlo:

- **Instalación mínima sin PyTorch:** `pip install -e "automontaje[dev]"` instala lo necesario para narración, mezcla, montaje y tests. `openai-whisper` pasa a un extra opcional `subtitulos`. Sin Whisper, pedir subtítulos falla con un mensaje claro que dice cómo instalarlo.
- **Tests sin red por defecto:** los tests que llaman al servicio real de Edge TTS se marcan como de internet y solo se ejecutan con `AEGS_TEST_INTERNET=1`; sin esa variable se omiten con motivo visible. El resto de la suite pasa sin red.
- **FFmpeg configurable:** las variables `AEGS_FFMPEG` y `AEGS_FFPROBE` (ruta a los binarios) tienen prioridad sobre el PATH, y todos los usos de ffmpeg/ffprobe del automontaje pasan por un único punto.
- **CI:** workflow de GitHub Actions en Ubuntu con Python 3.12 y 3.13, FFmpeg de apt, `pip install -e "automontaje[dev]"` y la suite.
- **Auditoría escrita:** `automontaje/doc/AUDITORIA_2026-10.md` con el estado real: qué se ejecutó, qué no (Whisper, Demucs, Real-ESRGAN, interfaz gráfica, Edge TTS real), defectos encontrados y el conflicto de tiempos con la animación (la escena dura lo que dura la voz; el clip se recorta o se congela).

Exclusiones: no cambiar el comportamiento de narración, mezcla ni montaje; no tocar `interfaz.py`, `mejorar_video.py` ni `superresolucion_video.py`; no instalar Whisper, Demucs ni Real-ESRGAN.
